# A + B

표준 입력에서 공백으로 구분된 정수 두 개를 읽고 합을 출력하는 Python 스크립트입니다.

```console
$ python app/main.py
1 2
3
```

테스트는 Python 표준 라이브러리의 `unittest`로 실행합니다.

```console
$ python -m unittest discover -s tests -v
```

## 가위바위보 3세판

컴퓨터와 가위바위보를 하려면 별도 스크립트를 실행합니다.

```console
$ python app/rock_paper_scissors.py
```

매번 `가위`, `바위`, `보` 중 하나를 입력하면 컴퓨터가 무작위로 선택하고
각 판의 승패와 현재 점수를 출력합니다. 먼저 2승을 거둔 쪽이 최종 승자입니다.
승패가 갈리는 판은 최대 3판이며, 무승부는 점수에 포함하지 않고 같은 판을
다시 진행합니다. 잘못된 입력은 다시 입력받으며 판이나 점수를 소모하지 않습니다.
입력을 종료하거나 Ctrl+C를 누르면 게임을 중단하고 종료 코드 1을 반환합니다.

예를 들어 플레이어가 `가위`, `가위`, `보`를 입력하고 컴퓨터가 각각
`보`, `바위`, `바위`를 선택했다면 최종 결과는 `최종 승자: 플레이어 (2:1)`입니다.
컴퓨터의 선택은 무작위이므로 실제 결과는 달라질 수 있습니다.

게임과 테스트는 Python 표준 라이브러리만 사용하며 추가 의존성이 필요하지 않습니다.
